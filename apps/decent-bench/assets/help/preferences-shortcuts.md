# Preferences and Keyboard Shortcuts

Use **Tools > Options / Preferences** to adjust Decent Bench for the way you work.

## Editor settings

Editor preferences control behavior such as line numbers, formatting choices, and related SQL editing options.

## Export settings

Export preferences let you choose defaults that are reused by export dialogs. This reduces repetitive setup when you often export in the same style.

## Layout settings

Layout preferences store pane visibility and workspace arrangement. If the screen gets too busy, use **View > Reset Layout** to return to a known layout.

## Snippets

Snippets are reusable SQL fragments. Use them for queries or patterns you type often, such as standard filters, common joins, or starter `SELECT` statements.

## Keyboard shortcuts

Use **Help > Keyboard Shortcuts** to see active shortcuts. You can also customize shortcuts in preferences.

Common defaults include:

- **F1** opens this Help Center.
- **Ctrl+Shift+P** opens the command palette.
- **Ctrl+Enter** runs a query.
- **Ctrl+Q** exits the app.

If a shortcut does not trigger, check whether focus is inside a text field or whether the command is currently disabled.

## Command palette

Use **View > Command Palette** when you know what you want to do but do not remember which menu contains it. Search for the command name, then press Enter.
